# 짠돌이의 에어컨 절약하기 (Penny-Pincher's Aircon Saver)

**문제해결과 컴퓨팅사고 · 사과나무 (2조)**

외출할 때 에어컨을 **켜두는 것**과 **끄고 나갔다가 귀가 후 다시 켜는 것** 중 어느 쪽이 전력을 덜 쓰는지 계산해 알려주는 콘솔 프로그램입니다.

## 실행 방법

Python 3.10 이상이 필요하며, 외부 라이브러리는 쓰지 않습니다 (표준 라이브러리 `sqlite3`만 사용).

```
python penny_pincher_gui.py              # 창(GUI) 버전
python penny_pincher_aircon_saver.py     # 콘솔 버전
```

두 버전은 같은 계산·DB 코드를 쓰며 화면만 다릅니다. GUI 버전은 결과를 막대그래프로도 보여줍니다.

1. 현재 실내 온도, 실외 온도, 희망 온도(℃)와 외출 시간(분)을 입력합니다.
2. 제조사(삼성 / LG / 캐리어)를 고르고 모델을 고릅니다.
   목록에 없는 에어컨이면 **기타**를 골라 소비전력을 직접 입력하고, 원하면 DB에 저장할 수 있습니다.
3. 귀가 시 예상 실내 온도, 두 방식의 소비전력량(Wh)과 추천이 출력됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `penny_pincher_gui.py` | **실행 파일 (GUI).** tkinter 창으로 입력과 결과 표시 |
| `penny_pincher_aircon_saver.py` | **실행 파일 (콘솔).** 텍스트로 입력과 결과 출력 |
| `simulator.py` | `Simulator`: 실내 온도 예측과 전력량 계산, `recommend()`: 추천 문구 (입출력 없음) |
| `aircon_db.py` | `AirconDatabase`: 에어컨 모델 DB(SQLite)와 시드 데이터 |
| `aircon.py` | `AirConditioner`: 에어컨 한 대의 데이터와 값 검증 |
| `prototype/` | 초기 프로토타입 (3개 모델 고정) |

`aircon.db`는 처음 실행할 때 자동으로 만들어집니다. 모든 `.py` 파일은 같은 폴더에 있어야 합니다.

## 계산 모델 (가정)

- 에어컨을 끄면 실내 온도가 시간당 (실외 − 실내) 온도차의 15%씩 오르며, 실외 온도를 넘지 않는다.
- 귀가 후 1℃ 낮추는 데 7분이 걸리고, 이때는 **정격** 소비전력으로 가동한다.
  (한국소비자원: 18평형 에어컨으로 35℃ → 26℃ 냉방에 약 1시간)
- 켜두는 경우는 같은 시간 구간(외출 + 재냉방 시간) 동안 가동한다. 현재 온도가 희망 온도보다 높으면
  먼저 **정격** 소비전력으로 희망 온도까지 냉방하고(1℃당 7분), 나머지 시간은 **최소** 소비전력으로 유지한다.
- 외출 시간은 0분 이상 1440분(24시간) 이하로 입력한다.
- 외출이 20분 이하이면 쾌적함을 위해 켜두기를 권장한다.

가정값은 `simulator.py` 맨 위의 상수에서 바꿀 수 있습니다.

## 모델 데이터 출처

제조사별 10개, 총 30개 모델이 들어 있으며, 결과 화면의 `※` 비고에 데이터 성격이 표시됩니다.

| 구분 | 삼성 | LG | 캐리어 |
|---|---|---|---|
| 공식 사양 | 1 | 2 | 0 |
| 정격은 공개 사양, 최소 소비전력은 추정 | 2 | 1 | 2 |
| 가상 데이터 (동급 평형 기준 추정, 실제 사양 아님) | 7 | 7 | 8 |

공개 사양 출처: 삼성전자·LG전자 제품 페이지, 캐리어 판매처 사양표, 다나와.
